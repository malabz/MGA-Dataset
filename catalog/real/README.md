# 真实数据

[返回首页](../../README.md) · [返回数据目录](../README.md)

收录可识别的组装基因组发布集合及真实数据基准集，按研究对象进入分类列表。

## 已收录分类

待收录。首次加入相关数据时创建分类页，并同步在这里和首页添加直接链接。

## 分类约定

| 分类 | 收录范围 | 首次收录时使用的文件名 |
| --- | --- | --- |
| 人类 | 仅包含人类的真实数据集 | `human.md` |
| 其他动物 | 不含人类的动物数据集 | `other-animals.md` |
| 植物 | 植物数据集 | `plants.md` |
| 真菌 | 真菌数据集 | `fungi.md` |
| 细菌与古菌 | 细菌、古菌或两者组成的数据集 | `bacteria-archaea.md` |
| 其他生物 | 不属于上述分组的单一类群数据集 | `other-organisms.md` |
| 跨类群集合 | 跨越上述分组，例如人类与其他灵长类共同组成的集合 | `cross-group.md` |

这些分组服务于检索，不代表严格的生物分类体系。同组内包含多个物种，不因此归为跨类群集合。未收录数据的分类不创建空页面。

## 分类列表格式

新分类页使用以下列，按数据集名称排序。数据集名称链接唯一详情文档，不在列表重复维护下载地址。

| 数据集 | 物种与比较范围 | 规模 | 组装完整性 | 用途 | 真值 |
| --- | --- | --- | --- | --- | --- |

规模必须注明计数单位；用途可以同时标注 MGA 与 Pangenome，潜在用途须注明“潜在”。字段定义见[数据说明](../../docs/data-guide.md)。
