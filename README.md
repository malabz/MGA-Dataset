# MGA-Dataset

持续收录多基因组比对（MGA）与泛基因组（Pangenome）研究的数据集说明、来源及下载入口，不存放数据文件。按研究对象浏览，组装级别区分 T2T、Chromosome、Scaffold 和 Contig 等。
