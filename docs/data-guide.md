# 数据说明与字段指南

[返回首页](../README.md) · [浏览数据目录](../catalog/README.md)

## 如何选择数据

先确定研究对象和比较范围，再看当前规模、组装级别及用途；需要准确性评测时进一步确认是否提供对应真值。持续集合可能追加数据，使用时应记录具体 accession 清单或仓库提交版本，再使用官方入口。

目录分类仅用于浏览。相同组装可能同时适用于 MGA 和 Pangenome，标签本身不代表已经验证适用性。

## 基本信息与规模

| 字段 | 填写要求 |
| --- | --- |
| 发布集合 | 正式名称、发布机构或项目、版本或发布日期；若无版本号，记录可识别的 accession 或样本清单 |
| 物种 | 名称与学名；多物种集合说明覆盖范围和物种数，较长清单链接来源 |
| 比较范围 | 种内、种间或两者混合；无法判断时填未明确 |
| 数据性质 | 真实组装、模拟数据、真实与模拟混合 |
| 规模 | 分别列明个体数、单倍型组装数、组装数、物种数等实际已知数量，不混用计数单位 |
| 文件与范围 | 实际提供的格式，完整基因组、染色体子集或区域子集；体积仅引用发布方明确提供的信息 |
| 版本对应 | 区分论文实际使用的子集、当前发布集合和不同版本，不将项目累计数量当作某次实验规模 |

未知信息填写“未明确”；尚待检查的信息填写“待核实”；不适用时说明原因。只有来源明确说明未提供时，才填写“未提供”。

## 用途与证据

- **MGA**：多基因组同源区域比对、全基因组比对或相关评测。
- **Pangenome**：多样本基因组整合、泛基因组或图构建。

用途可以多选，但须逐项标明依据属于原研究使用、后续研究使用或潜在用途。前两者链接对应论文或官方说明；潜在用途给出判断理由，在分类列表同样注明“潜在”，不能写成已有使用记录。

## 组装级别：T2T 单独展示

| 仓库级别 | 使用条件 |
| --- | --- |
| T2T | 发布者或论文明确支持该 accession 版本在指定组装范围内达到端粒到端粒；保存证据链接及范围 |
| Chromosome | 来源为染色体级，尚无本仓库已核实的 T2T 证据 |
| Scaffold | 来源为 Scaffold 级，尚无本仓库已核实的 T2T 证据 |
| Contig | 来源为 Contig 级，尚无本仓库已核实的 T2T 证据 |
| Complete Genome | 来源为完整基因组，但没有足以将其归为 T2T 的已核实证据；不强行降为 Chromosome |
| 未明确 | 来源未提供可靠组装级别 |
| 不适用 | 默认用于模拟数据，或该字段不适用的资源，说明原因 |

每条记录分开保存 **来源原始级别** 与 **仓库级别**。例如某组装在 NCBI 为 Complete Genome，发布者明确提供对应版本的 T2T 证据，则本仓库展示 T2T，原始级别仍保留 Complete Genome。原输入的级别与 NCBI 不同时，再保留输入字段以便追溯。

T2T 是本仓库独立展示级别，不声称它是 NCBI 原生字段。每个 accession 只属于一个仓库级别；汇总时 T2T 不重复计入染色体级。集合包含多个级别时展示分布，“混合”不是单条组装级别。

T2T 判定对象必须明确到组装、单倍型或所选染色体。局部染色体的结论不能推广至整个基因组、整个项目或其他版本。染色体级、Complete Genome、较高连续性或名称中含 T2T，均不能单独替代与版本范围对应的证据。证据未核实时保留原级别，并注明 T2T 待核实，不等同于判定非T2T。模拟数据所用参考组装的质量另行记录。

其他质量指标仅在来源提供时记录，同时保留指标名称、对象、版本和来源，不根据宣传用语推算数值。

## 真值与配套资源

真值状态使用“有、部分有、无、未明确”，并说明真值类型、覆盖范围、来源和可评测的对象。例如比对同源关系真值与变异真值不能互相替代。部分真值须说明缺失范围。

已有比对结果不自动视为真值，模拟数据也不自动视为具有可用真值。需要明确其生成依据、发布文件及适用限制。

样本清单、注释、图、已有比对、真值分别记录是否提供；下载链接集中在详情的下载入口表，配套资源部分解释内容与版本对应。

## 下载、访问与核验

每个入口明确资源名称、版本或范围、格式、链接及访问条件。优先提供官方主页、数据仓库、稳定 accession/DOI 及官方文件或批量入口；镜像必须明确标注。

访问条件区分公开下载、需要注册、需要申请与未明确。入口失效属于核验结果，单独记录。不要将临时登录链接作为长期下载地址，也不要猜测直链。

核验按入口记录日期、检查对象和结果。至少区分：

- **入口核验**：尚未检查、可访问、失效、受访问限制或无法确认。
- **文件内容验证**：本仓库只整理链接时填写“未验证（未下载）”。仅检查网页不能证明文件完整或符合描述。

引用论文与数据集本身的引用方式分别记录。原创整理文档许可不改变任何外部资源的版权、许可或申请要求。
