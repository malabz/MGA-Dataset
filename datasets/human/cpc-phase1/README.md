# CPC Phase I：中国 36 个人群泛基因组

[返回首页](../../../README.md) · [人类数据目录](../README.md) · [所属分类：人类](../../../catalog/real/human.md)

## 简介

Chinese Pangenome Consortium（CPC）一期是 Nature 2023 论文对应的固定发布集合，提供中国不同人群的分相组装及泛基因组。它与 [1KCP](../1kcp/README.md)、[APGp1](../apgp1/README.md) 是不同项目，分别收录和计数。

## 基本信息

| 字段 | 内容 |
| --- | --- |
| 正式名称 | A pangenome reference of 36 Chinese populations；CPC Phase I |
| 发布者与版本 | Chinese Pangenome Consortium；论文发表于 2023-06-14 |
| 集合标识 | PRJCA011422 |
| 物种与比较范围 | 人，*Homo sapiens*；种内 |
| 数据性质 | 真实 de novo 分相组装、泛基因组 |
| 核心规模 | 58 个核心样本、116 个单倍型组装；代表 36 个中国少数民族人群 |
| 扩展范围 | 官方 README 另列 6 个汉族组装；组装发布说明分为 57 个 HiFi 样本（含 10 个非核心样本）和 11 个 HiFi + Hi-C 样本 |
| 格式与范围 | 全基因组 FASTA；图格式与文件版本需按门户清单确认 |
| 数据体积 | 未明确 |

57 + 11 是发布说明中的样本分组，不能写成 68 个核心样本；额外 6 个组装也不能直接写成 6 名新增参与者。CPC 图和 CPC/HPRC 联合图的输入范围分别记录。

## 适用研究

| 用途 | 依据类型 | 使用方式 |
| --- | --- | --- |
| Pangenome | 原研究 | 中国人群多样性、非参考序列与泛基因组比较 |
| MGA | 潜在用途 | 使用分相组装进行种内多基因组比对 |

## 组装与质量

- **仓库组装级别**：未明确；未逐 accession 核对数据库级别，不根据 hifiasm 或“高质量”推定 Chromosome。
- **来源原始级别**：待逐组装整理。
- **T2T 证据与范围**：未确认一期全体组装的 T2T 声明；不把 CHM13 参考的级别继承给 CPC 组装。
- **已公布质量信息**：论文报告核心组装平均大小 3.01 Gb、平均 contiguity N50 约 35.63 Mb；不推广到非核心组装。
- **已知限制**：样本与组装文件范围不完全相同；需保留核心/非核心标签。
